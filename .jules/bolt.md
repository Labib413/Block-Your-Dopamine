## 2025-05-15 - Map-based Lookup Optimization
**Learning:** Linear array searches using `.find()` inside mapping functions or nested loops constitute a recurring O(N^2) performance bottleneck, especially when dealing with structural syllabus data like the HSC syllabus dataset.
**Action:** Consistently use Maps for O(1) lookups when iterating over or merging chapter-level data to ensure linear O(N+M) complexity and maintain a responsive UI.
