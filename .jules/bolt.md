## 2025-05-15 - [O(N^2) linear search bottleneck in Syllabus Progress]
**Learning:** Linear searches using `.find()` inside mapping functions for academic chapters constitute a recurring O(N^2) performance bottleneck when dealing with the HSC syllabus dataset (~80 chapters).
**Action:** Consistently use Maps for lookups when iterating over the HSC syllabus dataset or any collection where IDs are known in advance.
